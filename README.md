# Setzkasten

HEEx components and a design system for Phoenix admin backends, built on Tailwind 4 and daisyUI 5.
The name is German for a typesetter's type case: ready pieces to compose pages from.

- Function components for actions, forms, feedback, layout, data, navigation and overlays
- Light and dark daisyUI themes in one CSS file
- No JavaScript framework: `<dialog>`, `<details>` and `Phoenix.LiveView.JS`
- No inline styles, works under a strict CSP
- Design rules: [guides/design-system.md](guides/design-system.md)

## Install

For an app generated by `phx.new` 1.8 (Tailwind and daisyUI already set up).

1. `mix.exs`:

   ```elixir
   {:setzkasten, github: "shostakovich/setzkasten"}
   ```

2. `assets/css/app.css`: set `themes: false` on the daisyUI plugin, delete the generated
   `daisyui-theme` blocks and the `dark` variant, and import the package CSS after the plugin:

   ```css
   @import "lib/setzkasten/priv/static/setzkasten.css";
   ```

3. `assets/js/app.js`:

   ```js
   import {hooks as setzkastenHooks} from "phoenix-colocated/setzkasten"
   // hooks: {...colocatedHooks, ...setzkastenHooks}
   ```

4. `html_helpers/0` in `lib/my_app_web.ex`: `use Setzkasten`, then delete the generated
   components it replaces (`flash`, `button`, `input`, `header`, `table`, `list`, `icon`,
   `flash_group`, `theme_toggle`).

5. Root layout: `viewport-fit=cover` (the shell, dock, toasts and floating button keep to the
   safe areas), then `<.theme_meta />` and `<.theme_script />` instead of the generated theme
   script (it also applies a collapsed sidebar before paint):

   ```heex
   <meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover" />
   <.theme_meta />
   <.theme_script nonce={assigns[:csp_nonce]} />
   ```

   App layout: `<.flash_group flash={@flash} />` and one `<.confirm_dialog />`.

6. Fonts: serve the bundled Figtree from the endpoint (before your own `Plug.Static`) and preload
   it in the root layout's `<head>`. Without the plug the CSS falls back to a metric-matched Arial.

   ```elixir
   plug Plug.Static, at: "/setzkasten", from: {:setzkasten, "priv/static"}, only: ~w(fonts)
   ```

   ```heex
   <link rel="preload" as="font" type="font/woff2" crossorigin
     href="/setzkasten/fonts/Figtree-Variable.woff2" />
   ```

7. Optional config:

   ```elixir
   config :setzkasten,
     icons: MyAppWeb.Icons,   # use Setzkasten.Icons, path: "assets/vendor/lucide"
     plush: MyAppWeb.Plush,   # implements Setzkasten.Plush
     translate_error: {MyAppWeb.CoreComponents, :translate_error}
   ```

## Testing

`Setzkasten.Test.Confirm` drives the confirmation dialog in `Phoenix.LiveViewTest`:
`asked/3` returns the question a trigger asks (and fails if it sends its event without asking),
`confirm_click/4` runs the confirmed action (a push with its target, or a confirmed form submit),
`close_modal/3` closes a modal and sends its `on_cancel`.

```elixir
import Setzkasten.Test.Confirm

confirm_click(view, "#post-1-delete", "„Winter“ löschen?")
```
